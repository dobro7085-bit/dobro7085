AGM 감액량 분석 프로그램 사용 안내

1. 실행 방법
   - AGM_Reduction_Analysis.exe를 실행합니다.
   - 브라우저가 열리면 백데이터 Excel 파일을 업로드합니다.
   - 실행 중 검은색 콘솔 창은 프로그램 서버이므로 사용 중에는 닫지 마세요.

2. 연결 오류가 뜨는 경우
   - 브라우저에 "Connection error"가 뜨면 Streamlit 서버 연결이 끊긴 상태입니다.
   - AGM_Reduction_Analysis.exe 창을 닫았거나, PC가 절전 모드로 들어갔거나, 보안 프로그램이 실행 파일을 중지한 경우 발생할 수 있습니다.
   - 브라우저 탭을 닫고 AGM_Reduction_Analysis.exe를 다시 실행하세요.
   - 장시간 사용할 때는 Windows 전원 설정에서 절전 모드를 꺼두는 것을 권장합니다.

3. 기준값 변경 방법
   - 프로그램 화면에서 기준값 Excel 파일을 직접 업로드하면 해당 파일이 우선 적용됩니다.
   - 별도 업로드가 없으면 배포 폴더 안의 아래 파일을 자동 사용합니다.
     app\data\standard.xlsx
   - 기본 기준값을 바꾸려면 위 파일을 같은 이름으로 교체하세요.

4. 기준값 Excel 위치 기준
   - A열: 제품 형명
   - E열: UCL / 상한 규격
   - F열: 중심 규격 / 중심치
   - G열: LCL / 하한 규격

5. 주의사항
   - 동일 제품 형명에 기준값이 중복 등록되면 분석이 중단됩니다.
   - LCL이 UCL보다 큰 기준값은 오류로 처리됩니다.
   - 기준값 파일이 열린 상태에서 프로그램이 읽기 오류를 내면 Excel 파일을 닫고 다시 실행하세요.
