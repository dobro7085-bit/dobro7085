# AGM 감액량 분석 대시보드

백데이터 Excel 파일을 업로드하면 AGM 배터리 제품 형명별 감액량 품질 현황을 자동 분석하는 Python Streamlit 웹앱입니다. 날짜 범위와 제품 형명으로 조회할 수 있고, 기준값과 비교해 합격/부적합을 판정합니다.

## 프로젝트 구조

```text
감액량분석프로그램/
├─ app.py
├─ requirements.txt
├─ README.md
├─ generate_sample_data.py
├─ app/
│  └─ data/
│     └─ standard.xlsx              # 샘플 생성 스크립트 실행 시 생성
└─ sample/
   ├─ agm_sample_backdata.xlsx      # 샘플 생성 스크립트 실행 시 생성
   └─ agm_standard_sample.xlsx      # 샘플 생성 스크립트 실행 시 생성
```

## 설치 방법

```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
streamlit run app.py
```

Windows에서 `python`, `py`, `streamlit` 명령이 인식되지 않는 경우에는 프로젝트 폴더의 `run_app.bat` 파일을 실행하세요. 이 스크립트는 사용 가능한 Python을 찾아 `.venv` 가상환경을 만들고 필요한 패키지를 설치한 뒤 앱을 실행합니다.

## EXE 배포본 만들기

팀원에게 Python 설치 없이 배포하려면 아래 파일을 실행합니다.

```bat
build_exe.bat
```

빌드가 끝나면 아래 폴더가 생성됩니다.

```text
dist/AGM_Reduction_Analysis/
├─ AGM_Reduction_Analysis.exe
├─ app/data/standard.xlsx
└─ README_팀원용.txt
```

팀원에게는 `dist/AGM_Reduction_Analysis` 폴더 전체를 압축해서 전달하세요. 기준값을 바꿔야 할 때는 `app/data/standard.xlsx` 파일만 교체하면 됩니다.

## HTML 버전 실행 방법

Python 없이 브라우저에서 실행하려면 `index.html` 파일을 직접 열면 됩니다.

```text
index.html
```

HTML 버전은 브라우저에서 Excel을 읽고 그래프를 그리기 위해 SheetJS와 Plotly.js CDN을 사용합니다. 인터넷이 차단된 PC에서는 CDN 파일을 사내망 또는 로컬 파일로 내려받아 경로를 바꿔야 합니다.

샘플 Excel 파일을 먼저 만들려면 아래 명령을 실행합니다.

```bash
python generate_sample_data.py
```

## 백데이터 Excel 양식

기본 백데이터는 실제 데이터가 5행부터 시작한다고 가정합니다.

| 항목 | 기본 위치 | 설명 |
|---|---:|---|
| 날짜 | BS열 | 검사일자, 생산일자, 날짜, Date 등 |
| 시리얼넘버 | B열 | D열 형명이 비어 있을 때 형명 자동 생성에 사용 |
| 원본 형명 | D열 | 값이 있으면 그대로 분석용 제품 형명으로 사용 |
| 감액량 | BQ열 | 숫자로 변환 가능한 값만 분석 |

현장 양식이 바뀐 경우 사이드바에서 `수동 컬럼 선택` 모드로 날짜, 시리얼넘버, 제품 형명, 감액량 컬럼을 직접 선택할 수 있습니다.

날짜 값이 비어 있거나 변환되지 않는 경우에는 바로 위 행의 최종 날짜에 3초를 더해 자동 보정합니다. 첫 행처럼 참조할 위 행 날짜가 없으면 보정 실패로 처리됩니다.

## D열 형명 빈칸 자동 보정

제품 형명은 `보정 형명`을 최종 기준으로 사용합니다.

1. D열 원본 형명이 있으면 그대로 사용합니다.
2. D열이 비어 있으면 B열 시리얼넘버로 생성합니다.
3. 시리얼넘버 앞 3자리 숫자를 정수 변환해 선행 0을 제거합니다.
4. 시리얼넘버 뒤에서 두 번째 문자를 `_` 뒤에 붙입니다.
5. 시리얼넘버 네 번째 문자가 `A`이면 `1`, `C`이면 `3`을 붙입니다.

예시:

| 시리얼넘버 | 생성 형명 |
|---|---|
| 080C24K010206011H2 | AGM80_H3 |
| 105C24D170022502H3 | AGM105_H3 |
| 105A24D170022502H3 | AGM105_H1 |

전처리 후에는 `원본 형명`, `보정 형명`, `형명 생성 방식` 컬럼을 모두 확인할 수 있습니다. 생성 실패 데이터는 기준값 병합과 판정에서 제외됩니다.

## 기준값 Excel 양식

기준값은 아래 우선순위로 불러옵니다.

1. 사용자가 별도 기준값 Excel 파일 업로드
2. 백데이터 Excel 안의 `기준정보`, `기준`, `SPEC`, `Spec`, `Master` 시트 자동 인식
3. 실행 폴더의 `app/data/standard.xlsx` 파일 자동 로드

팀원이 기준값을 바꿔야 할 때는 배포 폴더 안의 `app/data/standard.xlsx` 파일만 같은 이름으로 교체하면 됩니다. EXE로 배포하더라도 기준값 파일은 EXE 내부가 아니라 외부 파일을 우선 읽도록 구성합니다.

기준값은 기본적으로 아래 고정 위치를 사용합니다.

| 항목 | 기본 위치 |
|---|---:|
| 제품 형명 | A열 |
| UCL / 상한규격 | E열 |
| 중심 규격 / 중심치 | F열 |
| LCL / 하한규격 | G열 |

기준값 파일 양식이 바뀐 경우에는 사이드바에서 `기준값 컬럼 모드`를 `수동 컬럼 선택`으로 바꿔 직접 지정할 수 있습니다.

동일 제품 형명에 기준값이 여러 번 등록되어 있으면 오류 메시지가 표시되며 분석이 중단됩니다. 기준값 파일에서 중복을 제거한 뒤 다시 업로드해야 합니다.

## 분석 로직

백데이터의 `보정 형명`과 기준값의 `제품 형명`을 기준으로 병합합니다.

판정 기준:

- 감액량 < LCL: 부적합, 이탈 방향 `하한 미달`
- 감액량 > UCL: 부적합, 이탈 방향 `상한 초과`
- LCL 이상 UCL 이하: 합격
- 기준값 없음, UCL/LCL 누락, LCL > UCL: 판정 제외

형명별 요약표는 총 댓수, 합격 수량, 부적합 수량, 부적합률, 평균/최소/최대/표준편차, 중심치, UCL, LCL을 계산합니다. 감액량 관련 값은 소수점 3자리, 부적합률은 소수점 2자리로 표시됩니다.

부적합률 계산 기준은 사이드바에서 선택할 수 있습니다.

- 기본값: `기준값이 있는 데이터만 판정 대상에 포함`
- 선택 옵션: `기준값 없는 데이터도 총 댓수에 포함`

## 사용 방법

1. `streamlit run app.py`로 대시보드를 실행합니다.
2. 사이드바에서 백데이터 Excel 파일을 업로드합니다. `.xlsx`, `.xlsm`, `.xls` 형식을 지원합니다.
3. 기준값 파일이 따로 있으면 업로드합니다. 없으면 백데이터 내 기준정보 시트 또는 `app/data/standard.xlsx`를 자동 사용합니다.
4. 필요 시 컬럼 매핑을 확인하거나 수동으로 변경합니다.
5. 날짜 범위와 제품 형명을 선택합니다.
6. KPI, 형명별 요약표, 그래프, 부적합 상세 목록을 확인합니다.
7. 요약, 부적합 상세, 필터 적용 데이터는 Excel로 다운로드할 수 있습니다.

## 그래프

- 형명별 분포 그래프: X축 제품 형명, Y축 감액량, 각 측정값을 점으로 표시하며 UCL/LCL/중심치를 형명별 선으로 표시합니다.
- 날짜 추이 그래프: X축 날짜, Y축 감액량, 단일 형명은 관리도 형태로 표시하고 여러 형명은 subplot으로 나눠 표시합니다.

점 위에 마우스를 올리면 날짜, 제품 형명, 감액량, 판정 결과, 이탈 방향, 시리얼넘버를 확인할 수 있습니다.

## 오류 발생 시 확인 사항

- 백데이터에 BQ열까지 존재하는지 확인합니다.
- 데이터 시작 행이 5행이 아닌 경우 사이드바에서 시작 행을 변경합니다.
- 날짜 컬럼이 올바르게 선택되어 있는지 확인합니다.
- 감액량 컬럼에 숫자로 변환할 수 없는 문자가 섞여 있는지 확인합니다.
- D열 형명이 비어 있는 데이터는 B열 시리얼넘버가 규칙에 맞는지 확인합니다.
- 기준값 파일에 제품 형명, 중심치, UCL, LCL 컬럼이 있는지 확인합니다.
- 동일 제품 형명 기준값이 중복 등록되어 있지 않은지 확인합니다.
- LCL이 UCL보다 큰 기준값은 수정해야 합니다.
